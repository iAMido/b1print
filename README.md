# B1 Print

אפליקציה לאייפון שהופכת תמונה למדבקה בשחור לבן למדפסת NIIMBOT B1 (הדפסה תרמית, 203 DPI, ראש הדפסה של 48 מ"מ).
הכל רץ בתוך Safari, והתמונות לא יוצאות מהטלפון.

**האפליקציה:** https://iamido.github.io/b1print/

## התקנה באייפון
1. פותחים את הקישור ב-**Safari**
2. לוחצים על כפתור השיתוף, ובוחרים **"הוסף למסך הבית"**
3. מעכשיו האפליקציה נפתחת במסך מלא מהאייקון, ועובדת גם בלי אינטרנט

## שימוש
1. **בחירת תמונה** מהגלריה, או **הדבקה מהלוח**
2. לקבלת רקע נקי: באפליקציית התמונות לוחצים לחיצה ארוכה על הנושא, בוחרים "העתק", וחוזרים ל"הדבקה מהלוח". ככה מופעלות גם האפשרויות "מדבקה" ו"צללית"
3. בוחרים גרסה ולוחצים **שיתוף / שמירה**: אפשר לשמור לתמונות, או לשלוח ישר לאפליקציית NIIMBOT
4. באפליקציית NIIMBOT: יוצרים מדבקה בגודל המתאים, מוסיפים את התמונה, מותחים אותה על כל המדבקה, ומכבים את עיבוד התמונה של האפליקציה (הקובץ כבר בשחור לבן)

## הגרסאות
| גרסה | מתאים ל |
|---|---|
| אטקינסון | ברירת המחדל לתמונות |
| ציור קווים | קווי מתאר חדים, מעט שחור |
| מדבקה | קווים עם מסגרת סביב הנושא (צריך רקע שקוף) |
| קו אחד | ציור בקו רציף אחד, אפשר לשמור גם כ-SVG |
| פלויד-סטיינברג | הכי הרבה פירוט |
| סקיצה | רישום עיפרון |
| רשת נקודות | מראה של עיתון ישן |
| חריטה | קווים כמו בשטר כסף |
| חותמת | לוגואים וטקסט |
| שבלונה | פופ ארט |
| צללית | צללית מלאה (צריך רקע שקוף) |

## אם ההדפסה כהה מדי
בהגדרות מזיזים את "בהירות דיתור" ימינה, או מורידים את ה-Density באפליקציית NIIMBOT.

## פיתוח
```bash
npm test               # בדיקות
npm run serve          # http://localhost:8000
```
בלי תלויות ובלי שלב בנייה. מבנה הפרויקט ומוסכמות הקוד מתועדים ב-`CLAUDE.md`.

גרסת פייתון (CLI + Streamlit, עם הסרת רקע מבוססת AI) נמצאת בתיקייה `python/`:
```bash
cd python && pip install -r requirements.txt
python -m b1print photo.jpg      # כל הגרסאות + דף השוואה
streamlit run app.py
```
